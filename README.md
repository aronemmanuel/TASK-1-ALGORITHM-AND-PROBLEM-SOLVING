# TASK-1-ALGORITHM-AND-PROBLEM-SOLVING
A C++ project implementing Merge Sort, Binary Search, and  Knapsack using Dynamic Programming, with test cases, time complexity analysis, and performance evaluation.

Algorithms Implemented
Merge Sort – Sorting using Divide and Conquer.
Binary Search – Efficient searching in a sorted array.
0/1 Knapsack – Optimization using Dynamic Programming.

Technologies Used
C++
GCC Compiler
VS Code / Dev-C++

⚙️ How to Run
Compile using GCC:
g++ -std=c++17 filename.cpp -o output.exe

📊 Complexity Analysis
Algorithm             Time Complexity
Merge Sort              O(n log n)
Binary Search            O(log n)
Knapsack                 O(n × W)
